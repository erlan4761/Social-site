# Дизайн-система Duet

Источник истины по цвету, типографике, ритму, глубине, состояниям и движению.
Значения живут в `web/src/styles/tokens.css`; этот документ объясняет, что чем
пользоваться и почему. Если правило и документ разошлись — прав файл, а документ
надо починить тем же коммитом.

**Главное правило:** голых `#hex`, `rgb()` и «случайных» отступов вне
`tokens.css` быть не должно. Проверка:

```bash
grep -nE "#[0-9a-fA-F]{3,8}" web/src/styles/*.css | grep -v tokens.css   # пусто
```

## 1. Откуда взялся этот облик

У Facebook взята **структура**: три зоны, постоянная навигация с иконками,
карточка как единица содержимого, предсказуемая плотность. От «Хроники»,
как проект назывался раньше, сохранено **чтение**: Literata 17 px в телах записей, колонка 36 rem,
изображение не режется в квадрат. Фирменный зелёный остаётся, синий Facebook
не берётся.

`.pane*` (messaging/conversation.css): имя выбрано другое как раз затем, чтобы два «треда»
не путались.

## 3. Темы

Тёмная тема включается **двумя путями**, и оба дают одинаковый результат:

```css
html[data-theme="dark"] { … }                       /* ручной выбор       */
@media (prefers-color-scheme: dark) {
  html:not([data-theme]) { … }                      /* системная, по умолчанию */
}
```

Блоки в `tokens.css` — байт в байт один и тот же текст. Меняешь один, меняй
второй; проверить равенство можно так:

```bash
awk '/^html\[data-theme="dark"\] \{$/{f=1;next} /^html:not\(\[data-theme\]\) \{$/{f=2;next} \
     /^\}$/{if(f)f=0} f==1{print>"b1"} f==2{print>"b2"}' web/src/styles/tokens.css && diff b1 b2
```

Проверено в Chrome: скриншот «системная тёмная без атрибута» и скриншот
«`data-theme="dark"` при системной светлой» совпадают побайтово (одинаковый
MD5). То же для светлой пары.

### Как переключать тему из кода

`web/src/theme.ts`:

| Экспорт | Что делает |
|---|---|
| `type ThemeChoice` | `'light' \| 'dark' \| 'auto'` |
| `THEME_KEY` | `'chronicle-theme'`, ключ в `localStorage` |
| `THEME_CHOICES` | порядок положений переключателя |
| `THEME_LABELS` | подписи: «Светлая», «Тёмная», «Как в системе» |
| `readTheme()` | что выбрано человеком (по умолчанию `'auto'`) |
| `systemPrefersDark()` | что просит система |
| `resolveTheme(choice?)` | какая тема видна сейчас: `'light'` или `'dark'` |
| `applyTheme(choice)` | ставит/снимает `data-theme` на `<html>` |
| `setTheme(choice)` | запоминает и применяет |
| `initTheme(onChange?)` | применяет сохранённое, подписывается на системную тему, возвращает отписку |

Важное: в режиме `auto` атрибут **снимается**, а не выставляется в `light` —
иначе перестанет работать медиазапрос.

Вспышки светлой темы при загрузке нет: `web/index.html` содержит синхронный
скрипт в `<head>`, который ставит `data-theme` до первой отрисовки. Измерено:
на `DOMContentLoaded` и в каждом из первых шести кадров `--canvas` уже `#0b1210`.
При переименовании ключа править **оба** места — `theme.ts` и `index.html`.

Пример переключателя (FE-02):

```tsx
const [choice, setChoice] = useState<ThemeChoice>(() => readTheme());
const pick = (c: ThemeChoice) => { setTheme(c); setChoice(c); };
// <button aria-pressed={choice === c} onClick={() => pick(c)}>{THEME_LABELS[c]}</button>
```

## 5. Типографика

Golos Text ведёт интерфейс, Literata — всё, что читают: тела записей,
комментарии, сообщения, био. Размер и интерлиньяж берутся парой.

| Токен | Размер | Интерлиньяж | Трекинг | Где |
|---|---|---|---|---|
| `--t-display` | `clamp(2rem, 1.4rem + 2.5vw, 2.75rem)` | `--lh-display` 1.05 | `--tr-display` −0.03em | логотип на входе, 404 |
| `--t-h1` | `1.5rem` | `--lh-h1` 1.2 | `--tr-h1` −0.02em | имя в профиле, заголовок экрана |
| `--t-h2` | `1.1875rem` | `--lh-h2` 1.3 | `--tr-h2` −0.015em | заголовок секции, название чата |
| `--t-read` | `1.0625rem` | `--lh-read` 1.65 | — | **тело записи, комментария, сообщения, био (Literata)** |
| `--t-body` | `0.9375rem` | `--lh-body` 1.5 | — | интерфейсный текст, кнопки |
| `--t-meta` | `0.8125rem` | `--lh-meta` 1.4 | — | время, счётчики, подписи |
| `--t-micro` | `0.75rem` | `--lh-micro` 1.3 | `--tr-micro` +0.02em | бейджи, ярлыки |

Правила:

- любые цифры-счётчики — `font-variant-numeric: tabular-nums`;
- заголовки — `text-wrap: balance` (в `base.css` для `h1…h4`), абзацы — `pretty`;
- длина строки текста для чтения — `--measure` (36 rem), это 60–75 знаков.

## 6. Ритм, радиусы, глубина

```
--s-1 4px   --s-2 8px   --s-3 12px  --s-4 16px
--s-5 24px  --s-6 32px  --s-7 48px  --s-8 96px
--r-xs 6px  --r-sm 10px --r-md 14px --r-lg 20px --r-full 999px
```

Отступ, которого нет в шкале, — повод объяснить его комментарием, а не
поставить молча.

Тени всегда двухслойные: близкий резкий слой плюс дальний мягкий. Одиночный
`box-shadow` — главный признак шаблона.

| Уровень | Когда |
|---|---|
| `--shadow-1` | карточка в покое (плюс `1px solid var(--line)`) |
| `--shadow-2` | карточка под курсором |
| `--shadow-3` | всплывающее: модалка, меню, подсказка, выпадающий список |
| `--ring` | мягкое кольцо фокуса, идёт **вместе** с `outline`, не вместо |

## 7. Сетка и точки перелома

```
--shell-max 82rem   --col-nav 16.5rem   --col-feed 36rem   --col-aside 19rem
--gutter 2rem (1.5rem на телефоне)      --topbar-h 3.5rem  --tabbar-h 3.75rem
--measure = --col-feed
--avatar 2.75rem (2.375rem на телефоне) --avatar-sm 1.75rem --avatar-lg 5rem (4rem)
--avatar-gap 1rem (0.75rem на телефоне)
```

Точки перелома — **три, больше не заводить**. В медиазапросах переменные не
работают, поэтому значения вписываются числом:

| Ширина | Что происходит |
|---|---|
| `< 46rem` | одна колонка, липкая шапка сверху, нижний таб-бар; левая и правая зоны не рендерятся |
| `46rem … 78rem` | левая навигация — узкая полоса `4.5rem` (иконки с `aria-label`), правая зона скрыта |
| `>= 78rem` | три зоны: `grid-template-columns: var(--col-nav) minmax(0, var(--col-feed)) var(--col-aside)`, центрируются в `--shell-max` |

На момент FE-01 в коде реализована прежняя двухзонная сетка и одна точка
`46rem`; трёхзонную включает FE-02, токены под неё уже готовы.

Правая зона наполняется **только честными данными** (мини-профиль, счётчики из
сессии, архив на профиле, футер). Нечем наполнить — зона схлопывается.

## 8. Состояния

Обязательны для каждого интерактивного элемента.

| Состояние | Как выглядит |
|---|---|
| Покой | как задано токеном |
| Наведение | фон `--surface-2` либо тень на шаг выше, переход `--dur-1` |
| Нажатие | `--surface-3`, кнопке — `transform: scale(.98)` |
| Фокус с клавиатуры | `outline: 2px solid var(--accent); outline-offset: 2px` **плюс** `--ring` (задано глобально в `base.css`) |
| Выбрано | текст `--accent`, фон `--accent-tint`, плюс `aria-current` / `aria-pressed` |
| Отключено | `opacity: .45`, `cursor: not-allowed`, цвет текста **не менять** |
| Загрузка | `.skeleton` формы контента, не слово «Загрузка…» |

Снимать `outline` можно только если видимое состояние фокуса даёт что-то
другое на том же месте (так сделано у `.search-box`: кольцо на обёртке,
`outline: none` на самом `input`).

## 9. Движение

```
--dur-1 120ms   --dur-2 200ms   --dur-3 320ms
--ease        cubic-bezier(.2, .8, .2, 1)
--ease-spring cubic-bezier(.34, 1.56, .64, 1)
```

Анимируются только `transform` и `opacity`. Разрешено: подъём карточки,
пружина на лайке и закладке, появление записи (`settle`), раскрытие ветки и
панели архива, затемнение подложки модалки. Запрещено: параллакс, анимации
дольше `--dur-3`, «прыжки» при загрузке, автопрокрутка.

`prefers-reduced-motion: reduce` гасит движение **сквозным правилом** в
`base.css` (все элементы, `animation-duration` и `transition-duration` в 1 мс)
и дополнительно адресными правилами в модулях. Проверено: при включённой
эмуляции `transition-duration` пункта навигации равен `0.001s`.

## 10. Доступность — что нельзя потерять

- `:focus-visible` виден на **каждом** интерактивном элементе;
- `.sr-only` — текст только для диктора, не удалять и не заменять на `display:none`;
- `.skip-link` — первая остановка Tab, ведёт на `#content`, видна только в фокусе
  (стиль готов в `base.css`, разметку ставит FE-02);
- `aria-current`, `aria-pressed`, `aria-selected`, `aria-haspopup`, `role="dialog"`
  и `aria-modal` — сохранять при любой переделке разметки;
- контраст текста: не ниже 4.5:1, для крупного (≥24 px или ≥18.66 px жирным) —
  3:1, в **обеих** темах;
- каждое поле формы имеет подпись (`<label class="field">` оборачивает `input`).

## 11. Как проверять свою работу

```bash
cd web && npm run build && npm run build:demo     # обе обязаны быть зелёными
npx vite preview --mode demo                       # → :4173/Social-site/
```

Флаг `--mode demo` обязателен: иначе `base: '/'` ломает пути и страница пустая.
Браузер — системный Chrome, собственный Chromium у Playwright не скачан:

```bash
npx playwright@1.63.0 screenshot --channel chrome --viewport-size "1440,900" \
  --full-page http://localhost:4173/Social-site/ shot.png
node -e "const {chromium}=require('playwright'); chromium.launch({channel:'chrome'})"
```

Обязательный минимум приёмки любой FE-задачи: скриншоты 375 / 768 / 1440 px в
обеих темах, `document.documentElement.scrollWidth <= window.innerWidth` на всех
трёх ширинах, ноль исключений и ноль ответов 4xx/5xx в консоли.

**Важно про витрину:** при полной перезагрузке `mockApi` заново создаёт сессию
пользователя `demo` — это заявлено в плашке. Поэтому экраны `/login`,
`/register`, `/forgot-password`, `/reset-password/:token` открываются только
переходами **внутри** приложения (нажать «Выйти», дальше по ссылкам), а не
через `page.goto`. Прямой `goto('/login')` вернёт ленту и создаст ложное
ощущение, что экран проверен.
